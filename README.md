# DoodleJump

SwiftUI-реализация классической аркадной игры **Doodle Jump**. Управляйте персонажем, перепрыгивая с платформы на платформу, чтобы набрать максимум очков.

## 🛠 Технологии

- Swift 5.9
- SwiftUI
- MVVM-подход (управление состоянием через `@State`, `@Published`)
- Анимации, таймеры и физика через `Timer` и `withAnimation`

## ⚙️ Структура

- `DoodleJumpApp.swift` — точка входа, настройка ContentView.
- `ContentView.swift` — основной игровой экран.
- `DoodlerView.swift` — представление игрока.
- `PlatformView.swift` — представление платформ.
- `Platform.swift` — модель платформы.
- `GameSettings.swift` — глобальные параметры игры (гравитация, размеры и т.п.).
- `ResultView.swift` — экран с результатом после завершения игры.

## 🎮 Геймплей

- Персонаж прыгает автоматически при столкновении с платформами.
- Платформы генерируются и двигаются вверх при наборе высоты.
- Игра завершается при падении персонажа за нижний край экрана.
- Результаты выводятся на отдельном экране.

## 🚀 Возможности для доработки

- Добавить боковые перемещения (наклон устройства или кнопки).
- Поддержка рекордов (например, через UserDefaults).
- Бонусы: trampolines, jetpacks, враги.
- Звук и музыкальное сопровождение.

## 🔧 Запуск

1. Открой `DoodleJump.xcodeproj` в Xcode.
2. Выберите любой симулятор (iPhone).
3. Построй и запусти проект.
